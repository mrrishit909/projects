Raw telemetry is cheap to filter and expensive to read.

The whole window is 148,392 tokens of JSON. A deterministic filter and a cheap triage agent keep 29 alerts and drop the rest, including 40 duplicate sensor reports.

Four investigators, four layers, in parallel.

Identity, endpoint, cloud and network agents each receive only their own bucket of alerts and return structured findings with evidence ids. The strongest model sees those findings, never the events: 2,829 tokens instead of 148,392, 52× less.
