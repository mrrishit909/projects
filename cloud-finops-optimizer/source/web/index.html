Cloud FinOps Optimizer

A synthetic multi-cloud estate of six accounts. The rightsizer finds idle and oversized spend under an SLO, a mixed-integer programme sizes the commitments, the changes become a Terraform pull request a second person approves, and after four simulated weeks the verifier measures what they really saved. …
The clouds, accounts, workloads, prices and bills are generated by a simulator in this repository; no real cloud account or billing data is used. The simulation's true savings are shown beside the verifier's estimate only because a simulator can know them. No outside model or service is called.
