Complaint Sorter

480 real vehicle-safety complaints filed with NHTSA in 2026. An LLM read each one and picked the part that failed (12 categories), flagged crashes or fires, and wrote a one-line summary, with no labelled examples. It is compared with the category the owner filed it under and with a classic word-count model trained on 35,000 older complaints. These are recorded results; this page never calls the API.

Data: NHTSA Office of Defects Investigation complaints (public domain) · model gpt-5.4-mini · code github.com/mrrishit909/complaint-sorter
