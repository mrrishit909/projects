How Chicago rides

5,951,516 bike-share rides, one question per section: how members and casual riders use the bikes differently, and where a membership campaign should go. Every number on this page comes from the SQL shown under it.

-- Data-quality profile: what the raw file contains and what each cleaning rule removed.
-- One row per check, so the whole profile reads as a small table.
WITH raw AS (
    SELECT ride_id, member_casual, started_at,
           ROUND((julianday(ended_at) - julianday(started_at)) * 86400000) / 60000.0 AS dur,   -- exact ms -> minutes
           ROW_NUMBER() OVER (PARTITION BY ride_id ORDER BY started_at) AS copy_no
    FROM trips_raw
)
SELECT 'Raw rides'                                   AS check_name, COUNT(*) AS rides FROM raw
UNION ALL SELECT 'Duplicate ride_id (extra copies)',  COUNT(*) FROM raw WHERE copy_no > 1
UNION ALL SELECT 'Under 1 minute',                    COUNT(*) FROM raw WHERE copy_no = 1 AND dur < 1
UNION ALL SELECT 'Over 24 hours',                     COUNT(*) FROM raw WHERE copy_no = 1 AND dur > 1440
UNION ALL SELECT 'Missing or odd rider type',         COUNT(*) FROM raw WHERE copy_no = 1 AND dur BETWEEN 1 AND 1440
                                                                          AND (member_casual IS NULL OR member_casual NOT IN ('member', 'casual'))
UNION ALL SELECT 'Started outside Sep 2025 - Aug 2026', COUNT(*) FROM raw WHERE copy_no = 1 AND dur BETWEEN 1 AND 1440
                                                       AND member_casual IN ('member', 'casual')
                                                       AND (started_at < '2025-09-01' OR started_at >= '2026-09-01')
UNION ALL SELECT 'Clean rides (kept)',                COUNT(*) FROM trips
UNION ALL SELECT 'Clean rides with no start station', COUNT(*) FROM trips WHERE start_station_name IS NULL
UNION ALL SELECT 'Clean rides with no end station',   COUNT(*) FROM trips WHERE end_station_name IS NULL;

1 · Members and casual riders ride differently

Members take 65.0% of rides and keep them short (median 8.7 min). Casual riders ride longer (median 11.3 min), far more on weekends (37.1% vs 23.3%), and are over three times as likely to end where they started (7.5% vs 2.2%): leisure, not commuting.

-- Q1. How differently do members and casual riders ride?
-- Median duration uses window functions (SQLite has no MEDIAN): number the rides by duration within
-- each rider type and average the middle one (odd count) or two (even count).
WITH ranked AS (
    SELECT member_casual, duration_min,
           ROW_NUMBER() OVER (PARTITION BY member_casual ORDER BY duration_min) AS rn,
           COUNT(*)     OVER (PARTITION BY member_casual)                       AS n
    FROM trips
),
medians AS (
    SELECT member_casual, ROUND(AVG(duration_min), 1) AS median_min
    FROM ranked
    WHERE rn IN ((n + 1) / 2, (n + 2) / 2)
    GROUP BY member_casual
)
SELECT t.member_casual                                                   AS rider_type,
       COUNT(*)                                                          AS rides,
       ROUND(100.0 * COUNT(*) / SUM(COUNT(*)) OVER (), 1)                AS share_pct,
       m.median_min,
       ROUND(AVG(t.duration_min), 1)                                     AS avg_min,
       ROUND(100.0 * AVG(t.weekday IN (0, 6)), 1)                        AS weekend_pct,
       ROUND(100.0 * AVG(t.rideable_type = 'electric_bike'), 1)          AS electric_pct,
       ROUND(100.0 * SUM(t.start_station_name = t.end_station_name)
             / SUM(t.start_station_name IS NOT NULL AND t.end_station_name IS NOT NULL), 1) AS round_trip_pct
FROM trips t JOIN medians m USING (member_casual)
GROUP BY t.member_casual
ORDER BY rides DESC;

2 · When: commute peaks vs an afternoon hump

Members have two peaks, 8:00 and 17:00: the commute. Casual riding has no morning peak; it builds through the day to 17:00. Saturday alone holds 21.1% of casual rides but only 12.7% of members'.

Show the SQL
-- Q2a. When in the day? Each hour's share of that rider type's rides, so the two shapes compare directly.
SELECT start_hour,
       member_casual AS rider_type,
       COUNT(*) AS rides,
       ROUND(100.0 * COUNT(*) / SUM(COUNT(*)) OVER (PARTITION BY member_casual), 2) AS pct_of_type
FROM trips
GROUP BY start_hour, member_casual
ORDER BY start_hour, rider_type;

-- Q3. Seasonality: rides per month, casual share, and month-over-month change (LAG).
WITH monthly AS (
    SELECT month,
           COUNT(*)                      AS rides,
           SUM(member_casual = 'casual') AS casual_rides
    FROM trips
    GROUP BY month
)
SELECT month,
       rides,
       casual_rides,
       ROUND(100.0 * casual_rides / rides, 1)                                  AS casual_share_pct,
       ROUND(100.0 * (rides - LAG(rides) OVER (ORDER BY month)) / LAG(rides) OVER (ORDER BY month), 1) AS mom_change_pct
FROM monthly
ORDER BY month;

-- Q4. Where do casual riders start? Top 15 stations by casual rides (stations with 1,000+ rides in the year),
-- with the casual share there. High-volume, high-share stations are where a membership campaign would go.
WITH by_station AS (
    SELECT start_station_name AS station,
           COUNT(*)                      AS rides,
           SUM(member_casual = 'casual') AS casual_rides
    FROM trips
    WHERE start_station_name IS NOT NULL
    GROUP BY start_station_name
    HAVING COUNT(*) >= 1000
)
SELECT RANK() OVER (ORDER BY casual_rides DESC)  AS rank,
       station,
       casual_rides,
       rides,
       ROUND(100.0 * casual_rides / rides, 1)    AS casual_share_pct
FROM by_station
ORDER BY casual_rides DESC
LIMIT 15;

-- Q5. The most common casual-rider routes (start -> end station), round trips included.
SELECT start_station_name                                   AS from_station,
       end_station_name                                     AS to_station,
       CASE WHEN start_station_name = end_station_name THEN 'yes' ELSE 'no' END AS round_trip,
       COUNT(*)                                             AS casual_rides,
       ROUND(AVG(duration_min), 1)                          AS avg_min
FROM trips
WHERE member_casual = 'casual'
  AND start_station_name IS NOT NULL AND end_station_name IS NOT NULL
GROUP BY start_station_name, end_station_name
ORDER BY casual_rides DESC
LIMIT 10;

6 · Ride length

4.0% of casual rides last an hour or more, against 0.7% of members'.

Show the SQL
-- Q6. How long are rides? Share of each rider type's rides in duration bands.
SELECT CASE WHEN duration_min < 5  THEN '1  under 5 min'
            WHEN duration_min < 10 THEN '2  5-10 min'
            WHEN duration_min < 20 THEN '3  10-20 min'
            WHEN duration_min < 30 THEN '4  20-30 min'
            WHEN duration_min < 60 THEN '5  30-60 min'
            ELSE                        '6  60 min +' END AS band,
       ROUND(100.0 * SUM(member_casual = 'member') / SUM(SUM(member_casual = 'member')) OVER (), 1) AS member_pct,
       ROUND(100.0 * SUM(member_casual = 'casual') / SUM(SUM(member_casual = 'casual')) OVER (), 1) AS casual_pct
FROM trips
GROUP BY band
ORDER BY band;

So what

  • Where: run a membership push at the lakefront and museum stations, starting with Navy Pier, DuSable Lake Shore Dr & Monroe St and Michigan Ave & Oak St.
  • When: May to September and weekend afternoons, when casual riders are out in the largest numbers.
  • What to say: casual riders take long leisure rides, so lead with what a membership saves on a 30-60 minute weekend loop, not on commuting.

These are recommendations drawn from the patterns above; testing them would need pricing data and a campaign experiment, which public trip data can't provide.
