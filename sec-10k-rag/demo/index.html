Ask the 10-K

An assistant that answers questions from five companies' latest annual reports (Apple, Microsoft, Amazon, Alphabet, NVIDIA) and cites the passage behind every fact, or says the filings don't contain the answer. These are recorded answers: this page is static, so it never calls the API or holds a key.

    How it scores

    30 test questions: 20 money questions graded against the SEC's own structured financial data (XBRL, which the assistant never sees), 5 fact questions, and 5 it should refuse. A money answer counts if it's within 0.5% and the cited passage contains the figure.

    Search: share of answerable test questions with the answer in the top 6 passages

    Search methodRecall

    Meaning search beat the hybrid I expected to win, so the assistant uses it. 30 direct questions is a small test: a real question with unusual wording can still miss, like the Alphabet capital-expenditures example above.
